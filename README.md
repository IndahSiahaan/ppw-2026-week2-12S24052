## Deskripsi Proyek
Proyek ini merupakan tugas praktikum pengembangan halaman web portofolio pribadi dan formulir konsultasi interaktif. Halaman ini dibangun menggunakan **HTML5 semantik**, framework **Bootstrap 5.3.3**, dan **CSS kustom** untuk menghasilkan tampilan antarmuka yang rapi, modern, dan responsif di berbagai ukuran layar (mobile, tablet, dan desktop).

---

## Fitur-Fitur Halaman
1. **Navigasi Responsif (Sticky Navbar):**
   * Navigasi menempel di bagian atas layar saat halaman digulir.
   * Dilengkapi menu hamburger (*collapse*) untuk perangkat layar kecil/smartphone.
2. **Bagian Profil (Hero Section):**
   * Menampilkan identitas pengembang, foto profil, status aktif, bio singkat, dan badge keahlian teknis.
3. **Showcase Proyek Akademik:**
   * Ditampilkan dalam bentuk kartu grid yang responsif.
   * Setiap kartu proyek memiliki tombol interaktif untuk membuka jendela **Modal** berisi rincian peran, perangkat yang digunakan, dan pencapaian proyek.
   * Terdapat rekapitulasi data proyek dalam format tabel yang rapi.
4. **Layanan Spesialisasi:**
   * Informasi bidang fokus layanan seperti *Web Frontend Design* dan *Software Modeling*.
5. **Formulir Konsultasi:**
   * Menggunakan *Floating Labels* dan *Input Groups* berikon.
   * Dilengkapi validasi form Bootstrap (peringatan jika data kosong atau format email belum sesuai).
6. **Desain & Gaya Tampilan:**
   * Tampilan modern dengan aksen warna cerah dan efek kartu transparan (*glassmorphism*).
   * Kode CSS bersih dan terstruktur menggunakan CSS Variables (`:root`) tanpa pemaksaan `!important`.

---

## Teknologi yang Digunakan
* **HTML5:** Struktur semantik halaman web.
* **CSS3:** Styling kustom, variabel warna, efek bayangan, dan animasi transisi.
* **Bootstrap 5.3.3 (CDN):** Sistem grid 12 kolom, komponen modal, navbar responsif, dan validasi form.
* **Bootstrap Icons 1.11.3 (CDN):** Kumpulan ikon antarmuka.
