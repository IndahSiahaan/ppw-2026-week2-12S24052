SRS & Workflow

Sistem Administrasi RS Balige

Proyek ini berfokus pada penyusunan dokumen Software Requirements Specification (SRS) secara komprehensif untuk mendigitalisasi proses administrasi dan registrasi pasien pada Rumah Sakit Balige.

Peran Utama: System Analyst
Perangkat Pemodelan: Bizagi Modeler & PlantUML
Fokus Analisis: BPMN 2.0, Functional & Non-Functional Requirements
Hasil Akhir: Dokumen SRS Bab 1-3 & Diagram BPMN Terstandarisasi

Pencapaian Kunci:

  • Memodelkan 5 alur proses utama mulai dari triase, pendaftaran poli, hingga pembayaran kasir.
  • Mengidentifikasi 28 butir kebutuhan fungsional dan 10 parameter keamanan rekam medis.
Software Architecture

Wander Del — Platform Open Trip

Perancangan arsitektur perangkat lunak untuk platform digital pariwisata Danau Toba yang mempertemukan traveler lokal dengan pemandu wisata berbasis komunitas.

Peran Utama: Software Architect
Artefak Desain: UML Class, Sequence, & Component Diagrams
Pola Arsitektur: Model-View-Controller (MVC) & RESTful Pattern
Hasil Akhir: System Architecture Specification Document

Pencapaian Kunci:

  • Menghasilkan diagram sekuens transaksi pemesanan paket open trip dan integrasi gateway pembayaran.
  • Merancang skema relasi entitas modular untuk skalabilitas modul katalog destinasi wisata.
Computer Networking

Analisis Protokol Jaringan Komputer

Investigasi empiris struktur paket komunikasi data pada lapisan transport dan aplikasi, mencakup penguraian header TCP, mekanisme sliding window, dan resolusi DNS query.

Peran Utama: Network Protocol Analyst
Perangkat Analisis: Wireshark Network Protocol Analyzer
Protokol yang Dianalisis: HTTP/1.1, TCP 3-Way Handshake, DNS (UDP), ICMP
Hasil Akhir: Laporan Analisis Forensik Lalu Lintas Jaringan

Pencapaian Kunci:

  • Menghitung Round Trip Time (RTT) dan menganalisis retransmisi paket pada koneksi lossy.
  • Melacak alur rekursif DNS query dari stub resolver ke root nameserver.
